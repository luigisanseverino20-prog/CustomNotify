# CustomNotify

Minecraft plugin for fully customizable join, quit and death messages.

## Features
- Custom join message with player name and real-time clock
- Custom quit message with player name and real-time clock
- Custom death message
- Toggle each message on/off individually
- Full color code support
- /cnreload command — reload config without server restart

## Compatibility
- Paper 1.21 / 1.21.1
- Java 21+

## Installation
1. Download the .jar file
2. Place it in your server's /plugins folder
3. Restart the server
